Remaining backend economic bypasses: **0**; frontend provider calls/credentials: **0**. `PROVIDER_MODEL_HEALTH` remains a reserved policy code, not an active external call.

The gateway now has explicit billing-class checks and local PostgreSQL tests for customer-wallet and included accounting. A real `/v1/responses` adapter prices measured tokens against a versioned `ResourceCostVersion` and refuses the network call if cost/FX configuration is missing. This core is not a substitute for migrating the call sites above. `PLAN_INCLUDED` is defined but inactive without an explicit entitlement. No per-operation commercial price, monthly allowance, or daily ceiling is inferred. Customer requests require a versioned configured commercial SKU and an operation maximum reservation; a nullable fixed price permits the versioned markup to price actual provider cost dynamically. Included migration calls require a same-tenant approved migration job and a migration cost center; platform calls require an active platform administrator with `platform.ai.internal` and preserve provider COGS without wallet debit. The approved 2× real-cost floor applies unless an audited Platform Super Admin override exists.
