## Architecture decision record

- Act identity: reuse global canonical `TipoActo`; the existing 38-row searchable service catalog links to it by `tipo_acto_id`. No second act catalog.
- Operational timing configuration: tenant-owned `ConfiguracionActo` hierarchy derived exclusively from ActorContext.
- Notary ownership: reuse canonical tenant-owned `Notaria`; no second notary catalog.
- Bank/fiduciary ownership: minimal tenant-private `CatalogoInstitucion`, because no semantically equivalent catalog existed.
- Files: reuse private Storage adapter and signed URLs. PostgreSQL stores metadata/provenance only.
- Audit/RBAC: reuse `AuditLog` and the canonical permission middleware.
- Operational boundary: no task/document/case instance generation, no signature date, no IA filling, and no changes to Expedientes or Mi Día.
