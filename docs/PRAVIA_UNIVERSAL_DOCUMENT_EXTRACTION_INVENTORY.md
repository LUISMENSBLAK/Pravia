## Hallazgos transversales comprobados

- `FiscalDocumentExtractionService` usa texto PDF y Tesseract local; `openaiDocument.service.ts` usa `aiGateway` para sus llamadas externas. **Esto no prueba bypass = 0 en todo el repositorio**.
- Búsqueda estática inicial de SDK/URL de proveedores (`new OpenAI`, `new Anthropic`, `api.openai.com`, llamadas `responses.create`/`chat.completions.create`) encontró sólo `platform/openaiProvider.adapter.ts`; faltan inspección de wrappers dinámicos y prueba de call sites antes de certificar bypass = 0.
- La CSF privada de dos páginas contiene texto digital. Antes del microfix, el extractor encontraba RFC/CP pero omitía nombre, domicilio y régimen; después, detecta campos de identidad, domicilio y un régimen descriptivo. El documento no muestra una clave SAT explícita en la capa extraída: la clave sigue **REVISIÓN REQUERIDA**, sin mapeo inventado.
- La CURP privada tiene texto digital: el parser local encuentra campos etiquetados y sólo propone CURP tras validación sintáctica. No se vinculó el PDF privado a una ficha ni se confirmó por persona. Un PDF sintético distinto sí completó carga, extracción, revisión UI, PostgreSQL/Storage y reload de la ficha existente.
- La INE privada no tiene capa de texto. Se localizaron dos imágenes en una página y se ensayó Tesseract local sobre página completa y cada imagen, con escalado, contraste y cuatro orientaciones. Su confianza máxima observada fue ~64/100. Apple Vision/macOS local leyó mejor el anverso (~81/100 de confianza media), pero no está integrado en el runtime Linux y un candidato CURP de OCR **no coincidió** con el PDF CURP; la imagen inferior no quedó acreditada. **OCR visual/identidad: NO VERIFICADO**, no fusionar datos automáticamente ni afirmar autenticidad.
- No hubo envío de los PDF privados a un proveedor externo, ni almacenamiento en fixtures o repositorio.
- Faltan por cada superficie: botón exacto, MIME/límite, permisos, política de wallet, job/retry, Storage/SHA, confirmación, auditoría, tenant adversarial, Chrome y 320/390 px. Ninguna fila `NO VERIFICADO` se cuenta como PASS.
